# Multi-Format Azure Data Engineering Project

End-to-end Azure Data Engineering project using:

- Azure Data Factory
- Azure Data Lake Storage Gen2
- CSV, JSON and Parquet files
- Bronze, Silver and Gold architecture
- Azure SQL Database (optional)
- GitHub integration and CI/CD
