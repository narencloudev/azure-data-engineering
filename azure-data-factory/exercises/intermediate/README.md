# Intermediate exercises

1. Use Get Metadata to check whether a file exists.
2. Use If Condition to choose a success or missing-file branch.
3. Use Lookup to read a small metadata configuration.
4. Use ForEach to process multiple configured files or tables.
5. Create a watermark-based incremental load design.
6. Add a failure path and capture useful error details.
7. Compare Schedule, Tumbling Window, and Event triggers for a given scenario.

**Deliverable:** a reusable pipeline design with parameters, control flow, and operational logging.
