# Beginner exercises

1. Draw the ADF architecture for a CSV copy.
2. Create a factory and explore the authoring canvas without enabling paid compute.
3. Create a linked service and dataset for a small sample file.
4. Build a pipeline with one Copy activity.
5. Run Debug and inspect the Monitor output.
6. Create a pipeline parameter for a source folder.
7. Explain the difference between a pipeline, activity, linked service, and dataset.

**Deliverable:** screenshots or notes showing the pipeline design, configuration, and run result.
