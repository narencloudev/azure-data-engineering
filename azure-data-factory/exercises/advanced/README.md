# Advanced exercises

1. Design a metadata-driven ingestion framework.
2. Define idempotency and duplicate-event handling.
3. Design retries, timeouts, and per-source failure handling.
4. Propose a Dev/Test/Prod Git and CI/CD process.
5. Define least-privilege identity and secret management.
6. Create a monitoring plan with run IDs, row counts, and error details.
7. Document recovery steps for a partially completed incremental load.

**Deliverable:** architecture diagram, configuration schema, failure strategy, and deployment checklist.
