# Schedule trigger

## Purpose
Starts a pipeline on a calendar schedule, such as daily at 01:00.

## Best for
Recurring jobs whose start time matters more than tracking each fixed processing window.

## Example
Run the daily ingestion pipeline every morning.

## Watch out
Consider time zone, daylight-saving behavior, start/end dates, and whether overlapping runs are safe.

## Exercise
Define a daily schedule and explain how you would prevent duplicate processing.
