# Azure Data Engineering Practice

A structured learning repository for my hands-on practice in SQL, Python, PySpark, Azure Data Factory, Azure services, Databricks, and Data Engineering interview preparation.

## Learning areas

- **SQL Server:** fundamentals, joins, functions, window functions, and business queries.
- **Python:** programming fundamentals and practical exercises.
- **PySpark:** DataFrames, transformations, aggregations, and exercises.
- **Azure Data Factory:** concepts, activities, and pipeline exercises.
- **Notes:** Azure, Databricks, and interview preparation.

## Repository structure

```text
sql/                    SQL concepts and query practice
python/                 Python fundamentals and exercises
pyspark/                PySpark DataFrame practice
azure-data-factory/     ADF concepts, activities, and exercises
notes/                  Technical notes and interview preparation
```

## How to use this repository

1. Create a separate file for each topic.
2. Include a short explanation and runnable example.
3. Add sample input or expected output when useful.
4. Record exercises and their solutions separately from concept notes.
5. Never commit passwords, connection strings, access keys, tokens, or other secrets.

This repository is for learning and practice. Larger end-to-end portfolio projects are maintained separately.


# Azure Data Engineering Learning Pack

This repository section is a structured theory and practice reference for **SQL Server (T-SQL)** and **Azure Data Factory (ADF)**.

## Folder guide
- `sql/`: SQL concepts from fundamentals through query development, analytics, transactions, and performance.
- `azure-data-factory/`: ADF architecture, authoring components, orchestration, incremental ingestion, monitoring, security, and CI/CD.

## How to study
1. Read one topic Markdown file at a time.
2. Run the SQL examples in your own SQL Server practice database where applicable.
3. For ADF, map each concept to the ADF Studio interface and use small test datasets.
4. Complete the practice questions at the end of each topic.
5. Add your own notes and screenshots only when they help explain what you learned.

## Important
- SQL examples target Microsoft SQL Server unless noted.
- `DATETRUNC` requires SQL Server 2022 or a compatible Azure SQL offering.
- Azure features, pricing, free allowances, and portal screens can change. Verify current service documentation and pricing before deploying resources.
- Never commit passwords, connection strings, access keys, tokens, or real personal/health data to GitHub.

## Suggested learning order
Start with SQL files `01`–`08`, then `09`–`15`, then `16`–`22`. For ADF, follow the numbered files from `01` to `17`.
