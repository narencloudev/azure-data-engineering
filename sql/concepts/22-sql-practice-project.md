# SQL Practice Project: Retail Orders Analysis

## Scenario
You have `Customers`, `Orders`, `OrderItems`, and `Products` tables. Your goal is to produce reliable business reporting.

## Suggested tasks
1. Inspect row counts, data types, NULLs, and duplicate keys.
2. Join orders to customers.
3. Calculate revenue by customer, product, and month.
4. Use `CASE` to classify order values.
5. Use `ROW_NUMBER` to find each customer's latest order.
6. Use `LAG` to compare monthly revenue.
7. Create a reporting view.
8. Create a stored procedure with a date-range parameter.
9. Add and evaluate an index for a common filter.
10. Document data-quality checks and assumptions.

## Deliverables
- SQL scripts organized by task.
- A README describing the dataset and business questions.
- Query outputs or screenshots where appropriate.
- Notes on performance and data-quality decisions.

## Portfolio tip
Do not publish real customer personal data, credentials, or confidential business records. Use synthetic or public sample data.
